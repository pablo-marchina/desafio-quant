# Documentacao

Esta pasta guarda material de entendimento, planejamento e prototipacao do
projeto. A raiz do repositorio fica reservada para os arquivos operacionais
principais, como `README.md`, `docker-compose.yml`, `requirements.txt`, `apps/`
e `scripts/`.

## Conteudo

- `GUIA_DO_PROJETO.md`: guia pessoal para entender e explicar arquitetura,
  tecnologias, fluxos e pastas. Fica ignorado pelo Git.
- `Seraphim_Scout_Projeto.md`: documento de visao e arquitetura do
  projeto.
- `STATUS_DO_PROJETO.md`: resumo historico do que ja foi implementado e dos
  proximos passos.
- `CHECKLIST_EXIGENCIAS_TAPI.md`: matriz de aderencia entre o documento do
  case/requisitos e o estado atual do projeto.
- `ROTEIRO_VIDEO_TAPI.md`: roteiro falado para gravar o video de entrega com
  cobertura das exigencias do checklist TAPI.
- `archive/`: documentos antigos ou copias de referencia.
- `design/`: prototipo visual estatico separado da interface real servida pela
  API.
- `private/`: notas pessoais ou planejamento local. Fica ignorado pelo Git.
