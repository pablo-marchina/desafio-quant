# NVIDIA TensorRT

Product: NVIDIA TensorRT
URL: https://docs.nvidia.com/deeplearning/tensorrt/latest/

NVIDIA TensorRT is an SDK for optimizing and accelerating deep learning inference on NVIDIA GPUs. It converts trained models, including models exported through ONNX, into optimized runtime engines and supports mixed precision, dynamic shapes, graph optimization, layer fusion, kernel selection, and production inference APIs.

TensorRT is relevant to computer-vision workloads such as industrial inspection, image and video analytics, object detection, classification, and segmentation when the evidence indicates a need for lower latency, higher throughput, or efficient GPU deployment. It can be paired with Triton Inference Server when the optimized engine must be served as a scalable production endpoint.

Keywords: TensorRT, computer vision, industrial inspection, image inference, video analytics, object detection, low latency, high throughput, GPU inference, ONNX, mixed precision
