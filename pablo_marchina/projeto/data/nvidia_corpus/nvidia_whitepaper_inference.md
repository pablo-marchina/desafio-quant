# NVIDIA Inference Optimization Guidance

## Product
NVIDIA Inference Optimization

## Gaps Addressed
- high_latency
- high_inference_cost

## Description
NVIDIA inference optimization guidance covers the system-level choices that determine serving performance, including model optimization, numerical precision, batching, parallel execution, memory use, and inference-server configuration. It is relevant when a startup must improve throughput, tail latency, hardware utilization, or cost per request.

Source: https://developer.nvidia.com/deep-learning-performance-training-inference

## Keywords
inference, latency, model, cost, performance

## Use Cases
- Diagnose latency and throughput bottlenecks
- Choose optimization and precision strategies
- Improve accelerator utilization during serving
- Define a reproducible inference benchmark
