## Description
TensorRT-LLM is an open-source NVIDIA library for optimizing and executing large language model inference on NVIDIA GPUs. It is relevant when a startup needs lower latency, higher throughput, efficient batching, quantization, parallel execution, or tighter control over the LLM serving stack.

Source: https://nvidia.github.io/TensorRT-LLM/

## Keywords
inference, production, open-source, latency, model, LLM

## Use Cases
- Optimize LLM execution for NVIDIA GPUs
- Apply quantization and runtime optimizations
- Scale inference across multiple GPUs
- Benchmark throughput, latency, and memory use
