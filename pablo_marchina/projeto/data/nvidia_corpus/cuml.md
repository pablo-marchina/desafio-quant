## Gaps Addressed

## Description
cuML provides GPU-accelerated machine-learning algorithms with interfaces designed to fit familiar Python and scikit-learn-style workflows. It is relevant when classical machine-learning training, clustering, dimensionality reduction, or model selection is constrained by CPU execution time.

Source: https://docs.rapids.ai/api/cuml/stable/

## Keywords
open-source, model, machine learning, training

## Use Cases
- Accelerate classical machine-learning training
- Run clustering and dimensionality reduction on GPUs
- Reduce iteration time for model selection
- Integrate accelerated estimators into Python workflows
