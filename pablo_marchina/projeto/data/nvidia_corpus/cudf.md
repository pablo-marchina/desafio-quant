# RAPIDS cuDF

## Gaps Addressed

## Description
cuDF is a GPU DataFrame library in the NVIDIA RAPIDS ecosystem. It provides pandas-like data manipulation on accelerated hardware and is relevant when tabular preprocessing, joins, aggregations, or feature engineering are bottlenecks in an AI data pipeline.

Source: https://docs.rapids.ai/api/cudf/stable/

## Keywords
open-source, data, dataframe, tabular, ETL

## Use Cases
- Accelerate tabular ETL and feature engineering
- Process large DataFrames on GPUs
- Reduce preprocessing latency before model training
- Move pandas-oriented workflows toward accelerated execution
