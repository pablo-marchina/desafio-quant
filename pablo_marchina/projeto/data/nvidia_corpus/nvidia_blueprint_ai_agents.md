## Description
NVIDIA AI Blueprints provide reference workflows and deployable patterns for building generative AI and agentic applications with NVIDIA components. They are relevant when a startup needs an implementation path for retrieval, tool use, orchestration, evaluation, or enterprise agent deployment rather than an isolated model endpoint.

Source: https://build.nvidia.com/nvidia/blueprints

## Keywords
agent, blueprint, RAG, reference workflow

## Use Cases
- Bootstrap an agentic application from a reference architecture
- Combine retrieval, models, tools, and guardrails
- Validate a production deployment pattern
- Reduce integration uncertainty across NVIDIA components
