# NVIDIA Omniverse

NVIDIA Omniverse é a plataforma para construir e operar aplicações de simulação 3D e gêmeos
digitais (digital twins), baseada no padrão aberto OpenUSD. Permite agregar dados e
ferramentas 3D de múltiplas fontes num ambiente físico-realista, fisicamente preciso.

## Capacidades
- **OpenUSD**: descrição e composição de cenas 3D interoperável entre ferramentas de CAD/DCC.
- **Simulação física (PhysX/RTX)**: ambientes fotorrealistas e fisicamente corretos para
  testar produtos e processos antes do mundo real.
- **Gêmeos digitais**: réplicas virtuais de fábricas, armazéns e equipamentos para otimização
  e treinamento de IA.
- **Geração de dados sintéticos**: ambientes para treinar modelos de visão e robótica
  (integra com Isaac).

## Quando recomendar
Indicado para startups de **simulação, indústria, 3D e gêmeos digitais**, ou que precisam de
dados sintéticos para treinar percepção/robótica. É uma tecnologia de domínio: o TAPI a
recomenda quando o perfil pede simulação 3D, mas não a dogfooda (não faz renderização 3D).
