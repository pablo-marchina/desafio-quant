# NVIDIA Morpheus

NVIDIA Morpheus é o framework de IA acelerado por GPU para **cibersegurança**, voltado a
inspecionar e analisar grandes volumes de dados de telemetria e tráfego em tempo real para
detectar ameaças que escapam de regras estáticas.

## Capacidades
- **Pipelines de streaming em GPU**: processa logs, pacotes e telemetria em alta vazão.
- **Detecção por IA**: identificação de phishing, vazamento de dados sensíveis, comportamento
  anômalo de usuários/máquinas e fraude, usando LLMs e modelos de ML.
- **Digital fingerprinting**: modela o comportamento típico de cada usuário/serviço para
  flagrar desvios.
- **Integração**: roda sobre RAPIDS/CUDA e integra-se a pipelines de segurança existentes.

## Quando recomendar
Indicado para startups de **cibersegurança, detecção de fraude e análise de telemetria** que
precisam processar volumes massivos em tempo real. É tecnologia de domínio — o TAPI a
recomenda quando o perfil pede segurança/análise de ameaças, mas não a dogfooda.
