# Entregas — Case NVIDIA × Inteli Academy

Repositório centralizado com as **18 entregas individuais** do Case NVIDIA realizado pelo **Inteli Academy**.

## Sobre o case

O desafio propôs soluções para identificar e analisar startups brasileiras de inteligência artificial, avaliar aderência a tecnologias NVIDIA e produzir recomendações apoiadas por evidências.

## Estrutura

```text
<nome_do_participante>/
├── README.md
├── demonstracao.md
└── projeto/
```

Os projetos foram incorporados diretamente e **não são submódulos Git**.
