# Entregas — Case NVIDIA × Inteli Academy

Repositório centralizado com todas as entregas do **Case NVIDIA de 2026**, realizado em parceria entre o **Inteli Academy** e a **NVIDIA**.

---

## Sobre o Case

O case proposto pela NVIDIA desafiou os alunos do Inteli Academy a desenvolverem **soluções de inteligência artificial** voltadas à identificação, análise e qualificação de startups brasileiras com potencial de adoção das tecnologias NVIDIA. Cada aluno construiu, de forma individual, uma solução funcional com coleta de dados, análise, recomendações, documentação e demonstração final.

---

## Estrutura do Repositório

Cada pasta corresponde a um aluno participante e segue a estrutura abaixo:

```text
<nome_do_aluno>/
├── README.md          → Informações da entrega
├── demonstracao.md    → Link da demonstração final
└── projeto/           → Repositório do projeto
```

## Como clonar este repositório

### 1. Instalar o Git

Caso ainda não tenha o Git instalado na sua máquina:

**Windows**
1. Acesse [https://git-scm.com/download/win](https://git-scm.com/download/win)
2. Baixe e execute o instalador
3. Siga os passos do instalador (pode deixar todas as opções padrão)
4. Após instalar, abra o **Git Bash** ou o **Prompt de Comando** e verifique:

```bash
git --version
```

**macOS**

```bash
# Via Homebrew (recomendado)
brew install git

# Ou via Xcode Command Line Tools
xcode-select --install
```

**Linux (Ubuntu/Debian)**

```bash
sudo apt update
sudo apt install git -y
```

---

### 2. Clonar o repositório

Abra o terminal ou Git Bash e execute:

```bash
git clone https://github.com/pablo-marchina/teste.git
```

Isso criará uma pasta `teste/` com toda a estrutura do repositório, incluindo os projetos e as demonstrações de cada aluno.

### 3. Executar um projeto individualmente

As instruções de instalação de dependências e execução de cada projeto estão no **README interno** de cada projeto. Para acessá-lo:

```bash
# Entrar na pasta do projeto de um aluno
cd teste/<nome_do_aluno>/projeto

# Ler as instruções de execução
cat README.md
```

> Cada aluno pode ter utilizado tecnologias e dependências diferentes. Siga sempre o README do projeto específico para garantir a execução correta.
